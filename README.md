# LSL Interpreter  

This project is a naive (work-in-progress) interpreter for LSL (Linden Scripting Language). It is designed to be suitable for automated testing purposes.  

## Features  
- Basic interpretation of LSL scripts.  
- Focused on simplicity and ease of use for testing.  

## Usage  
1. Clone the repository.  
2. Run the interpreter with your LSL script as input.  

## Future Plans  
- Expand LSL language support.  
- Improve performance and error handling.  
- Add more features for comprehensive testing.
